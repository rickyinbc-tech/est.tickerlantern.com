# Public SEO foundation — 25 October 2026

The canonical site is https://tickerlantern.com/. The homepage retains its existing Google Search Console URL-prefix verification tag. The former `est` and `www` hosts keep permanent redirects. Alternative article extensions and trailing slashes now permanently redirect to their canonical paths, preserving query parameters.

The build adds Organization, WebSite, Article/WebPage/CollectionPage and breadcrumb structured data, social preview metadata, a 1200×630 PNG, and research-information links to every generated public page. About and research/corrections policy pages explain the organizational byline and source/model limitations without asserting professional credentials or external review. The original restored company-research source remains hash-verified before metadata is added to its built output.

The eight public study landing routes previously inherited `noindex,nofollow` from their React template. The apex Worker now supplies their individual titles, descriptions, canonical URLs, structured data, and indexable robots directives. All visitors receive the same readable initial HTML summary; React replaces it with the existing interactive application. Only explicitly listed landing routes are changed. Unknown contracts, non-HTML responses, unavailable services, private paths, datasets and downloads retain their existing behavior and publication safeguards. No study source values or source-service deployment assets are changed.

The sitemap is generated from the actual guide inventory plus the two information pages and eight study routes. It excludes unknown contracts and API endpoints. Existing guide publication dates are preserved; this SEO release does not manufacture newer article modification dates. A real missing page returns 404 and includes a noindex directive.

## Verification and operations

Run `npm run build`, then `npm test`. Check the Worker package with `npx wrangler deploy --dry-run`. After deployment, run `python3 scripts/check-seo.py --output qa/seo/live-check.json` to check every sitemap URL, canonical, title, description, robots directive, structured-data graph and social metadata. The checker also validates robots.txt, the preview image and a real missing-page response. Raw QA stays in ignored `qa/`.

In Google Search Console select `https://tickerlantern.com/`, submit `sitemap.xml`, inspect the homepage and `/research/`, run a live test and request indexing if eligible. Record the returned submission and inspection outcomes separately from website deployment. A public sitemap and correct metadata do not establish that Google has fetched or indexed a URL. Search Console reports can lag; no indexing or ranking improvement is guaranteed. Review actual query/page performance and indexing reasons after Google processes the release.
